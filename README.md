# Enterprise SQL Clarification Engine

An AI-powered Text-to-SQL application that detects ambiguous business questions, asks users for clarification, and generates SQL queries.

Built using Streamlit, LangGraph, LangChain, and Groq.

## Features

- Convert natural language questions into SQL queries
- Detect ambiguous business questions
- Ask users for clarification when needed
- Maintain conversation state using LangGraph
- Generate structured SQL queries using an LLM
- Interactive web interface built with Streamlit

## Tech Stack

- Python
- Streamlit
- LangGraph
- LangChain
- Groq
- Pydantic
